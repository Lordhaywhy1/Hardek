# Hardek Telecommunication MVP — Delivery Outcomes

- [ ] Shared design system and connected demo state: React/TypeScript/Vite/Tailwind app with reusable navigation, cards, tables, dialogs, toasts, forms, route manifest, realistic centralized mock records, integer minor-unit currency calculations, localStorage persistence, append-only demo notifications/audit behavior, and Reset Demo Data.
- [ ] Public storefront commerce: responsive homepage, catalogue search/filter/sort, product details with variant-aware pricing, wishlist, comparison with highlighted differences, cart quantity/totals/promo/delivery behavior, and validated simulated checkout with Naira, bank transfer, card, and crypto display-only methods.
- [ ] Customer workflows: dashboard, profile, order history/details, synchronized simulated delivery tracking, wishlist, comparisons, loyalty points/rewards/redemption rules, pre-orders, auctions/bids, notifications, and shared support ticket creation.
- [ ] Staff, sales agent, and ambassador portals: KPI summaries, sales/points rules, charts, voting duplicate prevention, Employee of Month scoring/approval state, wholesale bulk-order calculation/history, commissions, referral conversion rules, leaderboard, and simulated redemption flows.
- [ ] Admin operations: overview charts/totals from shared state, product CRUD and image preview, inventory adjustments updating storefront availability, order search/status/cancellation/refund demonstration, staff/agent/ambassador management views, finance summaries and CSV export, audit log, content manager, campaigns/sponsors, support responses, and settings/reset actions.
- [ ] Validation and handoff: no dead links, responsive mobile navigation, production build passes, primary customer purchase flow works, shared status synchronization works, and README documents setup, roles, mock behavior, and backend integration boundaries.
- [x] Bidding and distress-sale controls: bidding is removed from the customer sidebar and presented through a reload-triggered storefront modal; admin controls approval, start time, end time, and duration; agent submissions remain hidden until approved; ended-auction UI includes simulated in-app and email payment/claim instructions.
- [x] Agent credit and VAT: agents can choose two or three instalments, the reducer records a 50% deposit and outstanding balance, unpaid balances block new bulk orders until settled, and checkout calculates/displays 7.5% VAT and stores it with the order.
- [x] Tracking and verification: `/track` provides only a tracking-number form with In Store, In Transit, Out for delivery, and Delivered stages; `/verify/:productId` provides a unique device code and QR-style inventory authenticity result.
- [x] Performance controls and mobile navigation: admin pages automatically identify the best sales representative, manage product points and monthly representative targets, customers can cast one vote per period with visible results, and portal mobile views include labeled bottom navigation while desktop sidebars remain intact.
